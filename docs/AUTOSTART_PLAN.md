# 0.4.0 本地自动启动

本轮采用已确认的源码版渐进方案：已有 Python 3.10+ 及服务依赖，一次注册 Windows Native Messaging 后，点击扩展可后台唤起服务。暂不提供免 Python 安装包、托盘或系统开机自启。

## 设计

- Native Messaging 只接受固定的 start/status 操作，不接收命令、路径或网页正文。当前用户注册，限定扩展 ID，提供注销脚本。
- 服务与浏览器宿主进程分离，关闭网页不结束服务。启动锁避免重复进程，端口占用不终止其他程序。停止脚本只请求本安装启动的进程退出。
- 扩展工具栏点击、打开面板和手动启动按钮可以唤起服务；定时健康检查只读，不反复拉起进程。多个启动请求共用同一 Promise，启动后重新核验 HTTP 服务。
- 固定源码扩展 ID；首次升级前导出旧收集箱，新增 ID 不自动迁移旧扩展存储。商店 ID 后续单独注册。
- 图标复用现有 Lucide Bird 品牌图形，生成 16/32/48/128 PNG，保留第三方许可证。
