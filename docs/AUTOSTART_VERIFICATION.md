# 0.4.0 自动启动验证

日期：2026-09-11。Windows、Python 3.12.7、Node 24.12、Chromium 131。源码版要求用户已有 Python 与依赖；不代表免环境安装包已完成。

## 已通过

- `npm run build`：扩展面板生成成功。
- `npm test`：15 项通过。新增并发启动合并、已运行复用、错误状态，以及“只读检查期间显式启动不能丢失”的回归测试。新增测试先观察到失败，再实现修复。
- `python -m pytest -q tests`：18 项通过，2 条已有 websockets 依赖弃用警告。覆盖 Native 消息长度与固定动作、真实后台服务启动/复用/停止/重启、端口占用不替换、精确扩展 ID 注册文件。
- `browser-send.cjs`：双页面批次收集、编辑与语言绑定、冲突、刷新/完整浏览器重启、Markdown 导出、实际 HTTP/MCP 及回执通过；包含 1440/390/320 三个视口。
- `browser-isolation.cjs`：未经修改的正式扩展封闭根与跨来源材料 DOM 隔离通过。
- `native-e2e.py` 首次运行中已执行并通过：浏览器调用真实 Native Messaging 宿主、中文/空格/& 安装路径、服务启动与并发复用、停止后显式重新唤起。使用独立端口和随机临时注册项，退出后清理测试注册及服务。
- 16/32/48/128 PNG 已生成；128px 图标与面板 390px 截图已人工查看，图标非空、布局无新增重叠。
- 代码审查发现并修复了健康检查期间用户启动请求被忽略的竞态，新增 Node 回归已通过。
